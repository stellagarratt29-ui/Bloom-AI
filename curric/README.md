# Curric

Plan a year-long school curriculum around term dates and holidays, track what's covered, and reschedule if you fall behind.

## Run it

```
npm install
npm start      # or: npm run web
npm test
```

## AI import

Create `.env` with a free [Groq](https://console.groq.com) key:

```
EXPO_PUBLIC_GROQ_KEY=your-key-here
```
